Hướng Dẫn Kết Nối ESP32-S3

ESP32-S3 gửi kết quả qua HTTP POST JSON tới máy chủ hoặc Web App:

{
  "user_id": 1,
  "heart_rate": 78,
  "spo2": 98,
  "temp": 36.6,
  "sys_bp": 118,
  "dia_bp": 78,
  "ai_status": "Bình thường"
}

Khi cảm biến vân tay AS608 quét trùng khớp user_id, ứng dụng sẽ tự động cập nhật đúng tên thành viên tương ứng!
